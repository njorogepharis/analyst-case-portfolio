# Hypotheses – Fintech Transaction Volume Decline

## Hypothesis 1: User Mix Shift
- Description: New users have lower transaction volume than returning users.
- Metric(s) to test:
  - Cohort transaction volume (new vs returning)
  - Churn vs new user inflow
- Priority: High, fast to test with existing data

## Hypothesis 2: Engagement Decay Among Existing Users
- Description: Existing users transact less over time.
- Metric(s) to test:
  - Avg transactions per active user
  - Cohort decay curves
- Priority: High

## Hypothesis 3: Pricing Competitiveness
- Description: Fee increases or less competitive pricing reduced transaction volume.
- Metric(s) to test:
  - Volume before vs after pricing changes
  - Transaction size by segment
  - Competitor pricing comparison
- Priority: Medium

## Hypothesis 4: Operational Friction
- Description: Transaction failures or processing delays reduced completed volume.
- Metric(s) to test:
  - Failed transactions vs attempted
  - Average processing time
  - System downtime reports
- Priority: Medium
