# Case 1: Fintech Transaction Volume Decline

## Problem Statement

A fintech company has observed a **15% decline in transaction volume** over a two‑month period. During the same period, the number of **active users has remained flat**. This divergence suggests that the issue is not driven by user acquisition or churn alone, but by changes in transaction behavior, user mix, pricing dynamics, or operational performance.

Senior leadership has requested an analytical assessment to:

* Identify the most likely drivers of the transaction volume decline
* Prioritize areas for deeper investigation
* Provide evidence‑based recommendations for corrective action

## Business Context

Transaction volume is a core revenue and engagement driver for the company. Sustained declines pose risks to:

* Revenue growth and profitability
* User lifetime value
* Competitive positioning in a crowded fintech market

Given limited time and data access, the analysis must focus on **high‑signal metrics** that can quickly narrow the problem space and guide decision‑making.

## Key Constraints and Assumptions

* Active users are measured consistently across periods
* No major reporting or data pipeline changes occurred during the analysis window
* Analysis prioritizes speed and diagnostic clarity over exhaustive modeling

## Analytical Objective

The objective of this analysis is to apply **hypothesis‑driven reasoning** to isolate whether the volume decline is primarily driven by:

* Changes in user behavior (engagement decay)
* Shifts in user composition (new vs returning users)
* Product or pricing effects
* Operational or system‑level friction

The output of this case will be an executive‑ready recommendation outlining the most likely cause(s) and the next best actions.
